# Тренажёр экзаменационных вопросов

Сайт по ТЗ «платформа тренировки экзаменационных вопросов (v2)». Главный набор — `files/CorpFin_300.xlsx` (300 вопросов, 20 тем).

## Запуск

Откройте `index.html` в браузере — сервер и сборка не нужны. Для публикации подойдёт любой статический хостинг (GitHub Pages и т. п.).

Вход по имени. Администратор — имя из `assets/js/config.js` (`adminNames`, по умолчанию «Админ»); **поменяйте его** перед публикацией.

## Наборы вопросов

Каждый набор — файл `sets/<id>.js`, список файлов — `sets/manifest.js`. Набор `primarySetId` из `config.js` открывается на главной, остальные — в разделе «Другие наборы». Все функции (4 режима, настройки, закладки, свои наборы, история, аналитика, источники) работают для любого набора одинаково.

**Добавить или обновить набор:**

```
python tools/build_set.py files/CorpFin_300.xlsx --id corpfin --title "Корпоративные финансы"
python tools/build_set.py path/to/Macro.xlsx --id macro --title "Макроэкономика" --description "..."
```

Скрипт (нужен `openpyxl`) пишет `sets/<id>.js` и обновляет `sets/manifest.js`. После обновления страницы изменения применяются по правилам ТЗ §3: ключ — №, новые строки добавляются, изменённые обновляются, пропавшие скрываются; строки с ошибками пропускаются и видны в админ-панели («Импорт и наборы» → «Журнал импорта»).

**Сменить главный набор:** поменяйте `primarySetId` в `assets/js/config.js`.
**Убрать набор:** удалите его файл из `sets/` и строку из `sets/manifest.js`.

Администратор может загрузить Excel и прямо в браузере (обновить набор с предпросмотром или создать новый), а затем скачать файл набора `.js`, чтобы добавить его в репозиторий.

Формат Excel — как у `CorpFin_300.xlsx`: лист «Лист1» (или первый лист) со столбцами №, Вопрос, A, B, C, D, Правильный вариант, Категория, Подсказка, Сложность (1–5), Мнемоника; необязательный лист «Источники» (№, Источник, Где используется, Ссылка).

## Структура

| Путь | Что внутри |
| --- | --- |
| `assets/js/config.js` | главный набор, админы, часовой пояс, размеры игр |
| `assets/js/sets.js` | проверка строк, импорт, мягкое удаление, категории |
| `assets/js/engine.js`, `templates.js` | подсчёт очков и движок обратной связи (§7–9) |
| `assets/js/games.js` | пул вопросов, «без повторов», игры, закладки, наборы, отчёты |
| `assets/js/store.js` | хранение данных (localStorage) и вход |
| `assets/js/views-*.js` | экраны |
| `tests/engine.test.js` | проверки по критериям приёмки: `node tests/engine.test.js` |

## Ограничения версии без сервера

- Данные (пользователи, игры, закладки, отчёты, правки админа) хранятся **в браузере** каждого пользователя: админ видит отчёты и статистику только с этого же браузера. Резервная копия — в админ-панели.
- Требование «клиент не получает правильный ответ до ответа» (ТЗ §12) без сервера не выполнимо: ответы есть в файле набора.
- Для общего хранения нужен сервер (по ТЗ — Node.js + PostgreSQL/SQLite); весь доступ к данным собран в `store.js`, его можно заменить вызовами API.
